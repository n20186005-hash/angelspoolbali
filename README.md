# Angel’s Billabong independent visitor guide

The original client-only language toggle is replaced by eight static HTML routes generated with Astro: Indonesian and English home, privacy, terms and cookie settings. Run `pnpm check` and `pnpm build`. Cloudflare serves `dist` through the ASSETS binding with Worker-first redirects and genuine 404 responses. The established convention is generated `dist` remains ignored; commit every required source/public asset and configuration. Do not upload source or development tooling as static assets.

All place information is scoped to its named source. A dated map listing is not proof of hours, access, safe water entry or operator affiliation. The pool name and historical photographs do not establish permission to enter the water. Follow local barriers, closures and instructions. General island, local attraction and parking payments must be checked separately.

One verified Commons photograph is used with its author/source/licence and archival date beside the image; resized WebP conversion and possible layout crop are disclosed. See the visible credit for CC BY-SA 4.0 terms. The remaining unverified baseline photographs and unused illustrations were removed. Photo adaptations retain CC BY-SA 4.0. Original text and code are separate.

Analytics is optional and off by default; legacy site choices are not automatically migrated. A refused choice is applied to the current tab before saving permanently. Storage exceptions preserve a session veto across navigation/refresh where session storage works and display a precise failure message. The old `ab-cache-` service worker namespace is retired without touching unrelated registrations or caches. No contact, booking or account endpoint is provided.
